# 更新说明 v0.6.0

`0.5.0 -> 0.6.0` 的主题：兼容 Trae 与 Qoder，并明确「方式三」中 base_url 与 Key 的配置说明。

## Trae / Qoder 适配

- **Trae 国际版**：`install.sh` / `install.ps1` 在检测到 `~/.trae` 时，把共享 skill 链接到 `~/.trae/skills/88api-image-gen`。
- **Trae 国内版（CN）**：检测到 `~/.trae-cn` 时链接到 `~/.trae-cn/skills/88api-image-gen`。
- **Qoder**：
  - 新增仓库根目录 `.qoder-plugin/plugin.json`（`skills: "./skills/"`），可按本地插件导入。
  - `install.sh` 在检测到 `~/.qoder` 时链接 skill 到 `~/.qoder/skills/88api-image-gen`。
- 安装脚本新增 target：`trae`、`qoder`；`--uninstall` 同步清理。

## 方式三：AI 客户端自助安装 + base_url

README「方式三」改为可直接粘贴的安装话术：

> 安装 https://github.com/DaYePython/88API-image-gen 仓库中的 88api-image-gen 插件，检查 Node.js 和本地图片处理环境；配置生图模型 base_url 为 `<你的base_url>`，key 为 `<你的key>`。

约定：

| 用户说法 | 插件命令 | 说明 |
| --- | --- | --- |
| base_url / API 根地址 / 网关 | `--set-api-root` | 默认 `https://88api.ai` |
| key / API Key | `--set-key` | 生图分组 Key |

共享 skill 与 Codex skill 的 Entry Check 已同步：用户在安装请求中同时给出 base_url 与 key 时，安装后立即写入本机配置，不得编造。

## 其他

- 版本号统一升到 `0.6.0`：`VERSION.txt`、各客户端 `plugin.json` / marketplace、共享 `SKILL.md`。
- 核心脚本 `generate.mjs` 生图逻辑无行为变化；base_url 仍走既有 `apiRoot` / `--set-api-root`。

## 兼容性

- 旧客户端（Codex / Claude / Cursor / Hermes）安装与配置路径不变。
- 已配置用户无需重写 Key；自定义 API 根地址仍读 `~/.agents/88api-image-gen-config.json`。
