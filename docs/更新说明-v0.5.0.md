# 更新说明 v0.5.0

`0.4.0 -> 0.5.0` 的主题：一个仓库同时适配 Codex、Claude Code、Cursor 和 Hermes，配置目录从 `~/.codex` 迁移到 `~/.agents`。

## 多客户端适配

仓库不再只是 Codex marketplace。核心脚本 `plugins/88api-image-gen/scripts/generate.mjs` 仍然只有一份，各客户端通过薄入口接入：

- **Codex**：保持原有 `.agents/plugins/marketplace.json` + `plugins/88api-image-gen/.codex-plugin/plugin.json` 结构，安装命令不变。
- **Claude Code**：新增 `.claude-plugin/marketplace.json` 和 `.claude-plugin/plugin.json`，支持 `/plugin marketplace add DaYePython/88API-image-gen` 后 `/plugin install 88api-image-gen@88api-plugins`。
- **Cursor**：新增 `.cursor-plugin/plugin.json`；也可以用 `install.sh` 把共享 skill 链接到 `~/.cursor/skills/`。
- **Hermes**：`install.sh` 把共享 skill 链接到 `~/.hermes/skills/`（绕开 Skills Guard 扫描器误报），并安装 `~/.hermes/desktop-plugins/88api-image-gen/` 桌面生图面板。桌面面板是命令生成器形态（桌面插件沙箱不允许 spawn 子进程）：填好提示词、比例、参考图后复制命令，粘贴到 Hermes 会话由 agent 执行。

## 共享 Skill

新增 `skills/88api-image-gen/SKILL.md`，是 Claude Code、Cursor、Hermes 共用的客户端中立技能文件：

- 脚本路径不写死，按 `88API_IMAGE_GEN_SCRIPT` 环境变量、仓库相对布局、Codex 旧安装路径的顺序解析。
- 保留了 Codex 版 SKILL.md 的全部计费警告、worker 池规则、`[NO-RETRY]` 语义、2K 比例矩阵和批量工作流说明。
- 原 `plugins/88api-image-gen/skills/88api-image-gen/SKILL.md` 继续保留给 Codex 插件使用。

## 配置目录迁移

- 配置文件从 `~/.codex/88api-image-gen-config.json` 迁到 `~/.agents/88api-image-gen-config.json`。
- 升级后首次运行任意命令会自动读取旧位置并重存到新位置，Key 不需要重新配置。
- 更早的 `fhl-image-gen-config.json` 也在迁移链内，历史配置都能自动衔接。
- 旧文件只读不删，新路径一旦写入就优先使用。

## 安装脚本

- 新增 `install.sh`（macOS / Linux）和 `install.ps1`（Windows）。
- 自动检测 `~/.claude`、`~/.cursor`、`~/.hermes`，对存在的客户端创建 skill 链接；Windows 使用免提权的目录 junction。
- 同时检查 Node.js 版本和各平台精确裁剪依赖（macOS `sips` / Linux ImageMagick）。
- 支持 `--target claude|cursor|hermes|agents` 单端安装和 `--uninstall` 完整卸载。

## 其他

- GitHub 仓库所有者从 `blackdm666` 更换为 `DaYePython`，README、插件清单、项目说明中的所有安装命令和链接已同步。
- 版本号统一升到 `0.5.0`：`VERSION.txt`、`.codex-plugin/plugin.json`、`.claude-plugin/`、`.cursor-plugin/`、共享 SKILL.md。

## 兼容性

- 生图逻辑、API 调用、worker 调度、`[NO-RETRY]` 语义与 `0.4.0` 完全一致，无行为变化。
- Codex 旧用户无需任何操作：旧配置自动迁移，旧安装路径 `$HOME/plugins/88api-image-gen/` 仍是 skill 的兜底解析位置。
